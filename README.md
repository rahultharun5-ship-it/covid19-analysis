## About

Analysis of the global COVID-19 dataset using Python. The dataset is taken from GitHub and contains country-wise COVID-19 statistics.

## Libraries Used

- Pandas
- NumPy
- Seaborn
- Matplotlib

## Steps Covered

1. Import dataset using Pandas
2. High level data understanding
3. Low level data understanding
4. Filter required columns
5. Data cleaning
6. Date time formatting
7. Data aggregation using groupby
8. Feature engineering
9. Data visualization
10. Save output as CSV

## How to Run

```
pip install pandas numpy seaborn matplotlib jupyter
jupyter notebook COVID19_Global_Analysis.ipynb
```
